# История изменений

## v0.1.0 — 2026-11-25

- Подключение к узлам Tailscale на Windows и Linux, проверка доступности узла перед командой.
- RDP для Windows-серверов и настройка OpenSSH через WinRM либо установочный набор для RDP.
- Передача установочного набора через Taildrop с запасным вариантом через буфер обмена; получение имени SSH-пользователя обратно через Taildrop.
- Сохранение RDP-пароля из `password.txt` в Windows Credential Manager перед подключением.
- Полные шаблоны `config.bat` и `password.txt` с комментариями; отдельные меню и команды для Windows и Linux.

Проверки перед выпуском: синтаксис PowerShell, метаданные команд, выбор меню для обеих ОС, тест логики Tailscale, доступность RDP и SSH на тестовом Windows-узле. Вход RDP с сохранённым паролем и подключение к реальному Linux-узлу не проверялись.
